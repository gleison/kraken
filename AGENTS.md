# Premissas de código

- Use nomes de métodos e parâmetros que expressem seu significado.
- Escreva comentários somente quando forem estritamente necessários.
- Programe para interfaces; mantenha implementações separadas e substituíveis.
- Mantenha cada função com uma única responsabilidade.

# Backlog e commits

- Não altere `docs/kraken-2.0/backlog.md` para registrar progresso ou entregas.
- Registre as entregas pelos commits, usando o identificador e o título da
  tarefa, por exemplo: `K-003 — Criar o domínio do plano executável`.
