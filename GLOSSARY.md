# Glossário

| Termo | Definição |
| --- | --- |
| Projeto | Unidade de trabalho gerenciada pelo Kraken, associada a um repositório Git, incluindo seus requisitos, decisões e tarefas. |
| Sessão | Período de interação com o Kraken que pode ser interrompido e retomado. |
| Planejamento | Descoberta e consolidação do objetivo, escopo, decisões, restrições e trabalho necessário antes da implementação. |
| Plano | Conjunto versionado de requisitos, decisões, contratos, dependências, composição do time e limites propostos para um projeto. |
| Aprovação do plano | Consentimento explícito do usuário para executar uma versão identificada do plano. |
| Orquestrador | Coordenador que mantém o contexto do projeto, distribui trabalho, acompanha evidências e conduz correções e integração dentro do plano aprovado. |
| Agente especializado | Participante responsável por uma atribuição delimitada, com papel, contexto e recursos definidos. |
| Papel | Conjunto de responsabilidades e critérios de entrega que pode ser atribuído a um agente. |
| Skill | Procedimento reutilizável que orienta como um agente realiza determinado tipo de trabalho. |
| Contrato de tarefa | Definição autossuficiente do resultado esperado, escopo, dependências, restrições e critérios de aceitação de uma tarefa. |
| Feedforward | Orientação fornecida antes da execução para tornar explícitos o resultado esperado e as condições para alcançá-lo. |
| Feedback | Retorno baseado em evidências que identifica o resultado obtido, suas divergências e a correção necessária. |
| Revisão com contexto novo | Avaliação baseada nos artefatos e referências fornecidos, sem depender do histórico da conversa que os produziu. |
| Harness | Conjunto de mecanismos que torna o trabalho dos agentes executável, verificável, observável e limitado pelas regras do projeto. |
| Evidência | Registro verificável de uma observação ou checagem, associado ao resultado e à versão que foi avaliada. |
| Tentativa | Execução delimitada de uma tarefa ou etapa, com resultado e consumo próprios. |
| Integração | Incorporação dos resultados aprovados à linha de trabalho compartilhada, seguida da validação do conjunto. |
| Bloqueio | Condição que impede o avanço de uma tarefa até que um pré-requisito seja satisfeito. |
| Escalonamento | Devolução ao usuário de uma decisão que o sistema não pode resolver dentro da autorização vigente. |
